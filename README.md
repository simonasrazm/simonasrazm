# Simonas Razminas

I build dark software factories, reusable skills and the systems around AI agents.

I started building dark software factories before it was cool. They are called dark factories because no one would read the generated code (including code of tests).

Useful work delegation to AI still needs clear intent, enough context, evidence, review and someone responsible for the decisions. I work on that layer, where AI meets engineering, product and security.

## What I build

- [Skills](https://github.com/simonasrazm/skills) - professional tools for productivity, nasty bugs, hard decisions and software that needs to work.
- [SFLO](https://github.com/simonasrazm/simon-factory-lights-out) - a gated pipeline for building software with AI agents.
- [Finally done](https://finallydone.ai/) - AI adoption, software factories, engineering and security work, plus the products I am building.

Install the open-source skill collection:

```shell
npx skills@latest add simonasrazm/skills
```
